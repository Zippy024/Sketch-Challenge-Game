SKETCH CHALLENGE / MENU V3 -- CLEAN UI
===================================

This package is an update to the user's Godot 4.7.2 project.

Changes:
- No large floor-plan preview image on the Home screen.
- No decorative grid or oversized colored circles in the menus.
- Light neutral background, white cards, dark text, teal accents.
- Header uses a fixed-width SC logo, preventing its letters from stacking.
- Compact Japanese / Myanmar language buttons.
- Progress is shown on its own line, preventing vertical character stacking.
- Six horizontal Level rows in a vertically scrolling panel.
- Level 1 and unlocked Level 2 launch gameplay directly; no extra START LEVEL 1 screen.
- Existing bilingual Theme, sounds, drawing, game scenes and progress logic retained.

Run:
1. Extract into a NEW folder.
2. Open project.godot in Godot 4.7.2.
3. Press F5, choose START GAME, then Level 1.
4. Test Stage 1/2 and the MENU button. Do not overwrite your good project until it works.
5. GitHub Desktop: copy project sources to the clone, but keep .github/workflows/main.yml.
6. Commit, Push and check GitHub Actions before opening GitHub Pages.

Notes:
- The reference sketch image remains in the project for Stage 1's actual gameplay.
- The large image was removed ONLY from the Home menu.
- Levels 3-6 are visible placeholders, not yet playable.
- No API keys or secrets are included. Add Gemini/API integration via server-side backend.
- This ZIP has not been run in a local Godot binary/browser in this environment.
