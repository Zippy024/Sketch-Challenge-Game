Sketch Challenge – Stage 3 original S-Class image replacement kit
===============================================================
IMPORTANT: This kit DOES NOT contain Panasonic original HQ images.
The public Panasonic iHOW'S site could be verified, but the 3D planner image
assets were not obtainable in this session. Generated illustrations should
NOT be substituted because layout details are educationally important.

မူရင်း Panasonic S-Class ပုံများကို ရရှိမှသာ အောက်ပါ အမည်များဖြင့်
Original_PNG folder ထဲသို့ PNG ဖိုင်အစစ်များ ထည့်ပါ။

For current Stage3.gd version:
  Q1 – 5 layouts
    q1_1.png = I型
    q1_2.png = L型
    q1_3.png = 対面
    q1_4.png = II型
    q1_5.png = アイランド

  Q2 – 4 alternatives (current game asks 対面 layout detail)
    q2_1.png = フルフラット
    q2_2.png = 耐力壁
    q2_3.png = フロート
    q2_4.png = ラウンドアクセス

  Important: The separate I型 detailed choices in your Panasonic screenshot
  (I型 / フロア＆フード / サイドフード / センターフード / フロアのみ)
  are NOT the currently implemented Q2 choice set. Do not overwrite q2_1
  through q2_4 with I型 variants. That would break question/answer alignment.

HOW TO INSTALL:
  1. Save your actual original PNG images into Original_PNG using the names above.
  2. Close Godot.
  3. Drag your Godot project folder (the folder containing project.godot)
     onto Install_Original_PNGs.bat.
  4. Script validates PNG format and all nine required filenames,
     backs up existing Stage3Assets folder, and copies originals.
  5. Reopen Godot, wait for import, and test Stage 3 (Q1/Q2).

Panasonic S-Class planner:
  https://sumai.panasonic.jp/ihows/#ctg_kitchen

No Stage 1, Stage 2, Gemini, audio, menu, or gameplay logic is modified
by this kit. Only nine PNG files are copied when all genuine image files exist.
