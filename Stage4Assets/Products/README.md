# Stage 4 product images

This folder contains 15 catalog-based generated selection images supplied for Stage 4: five accepted sinks, five replacement gas cooktops and five replacement range hoods. Earlier rejected images are excluded.

- `Sinks/`: stainless M, stainless S, G sink 76, Raku-suru and Mu-black.
- `Cooktops/`: JUASDS17WS, JUAED21WB, JUASHW38R7, JUASW28P1W and JUASG32T1V. Names identify the reference catalog entries, not verified engineering specifications.
- `Hoods/`: Hottokleen silver, Smart Hood II black, Stylish, Thin and Boots-type sirocco.
- `Faucets/`: five temporary native mesh thumbnails. The owner's original faucet photo files are not present in this checkout; see the folder README before replacing them.

The 15 catalog images are reference-based generated illustrations, not original manufacturer photographs. All 20 thumbnails are 2D selection images; `ProductGeometry.gd` supplies the separate approximate interactive 3D representations. `manifest.json` records source category, sizes and checksums.

Stage 4 currently implements layout, independent selections, preview/cancel/confirm, camera controls, reference enlargement and saved Continue. Customer dialogue and answer grading are intentionally deferred: the speech placeholder is empty and Check Answer is disabled. No Stage 4 score or completion is awarded.
