Kitchen Layout Clean - Godot 4.7
1. Back up your existing Main.gd and DrawingCanvas.gd.
2. Replace those TWO scripts with the included files. DO NOT combine them.
3. Copy customer_icon.png, staff_icon.png and reference_sketch.png into your existing project folder if not already present.
4. Press Ctrl+S and F5.
5. Connected OFF = two clicks per independent line; Connected ON = click each next corner, right-click to finish.
6. Middle mouse drag = pan; mouse wheel = zoom; Shift = orthogonal constraint.
7. OK checks four sides, endpoints and dimensions, with an 80mm tolerance.
